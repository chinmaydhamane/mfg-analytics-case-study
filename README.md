# Manufacturing Analytics Case Study: CNC Components Plant

Arihant Analytics case study on **synthetic data** (fictional plant, seeded and reproducible). It covers:

1. OEE analysis and downtime Pareto
2. Predictive maintenance (Random Forest, time-based split)
3. Quality control and SPC (X-bar chart)
4. Business impact in ₹

Open `case_study_cnc_plant.ipynb`. Requires `numpy pandas matplotlib scikit-learn`.
